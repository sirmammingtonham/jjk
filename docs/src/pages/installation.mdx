# Installation

## Requirements

`jjk` runs **in-process**: it links the [`jj-lib`](https://crates.io/crates/jj-lib) crate (built against
jj 0.41.x) for all version-control operations and the [`octocrab`](https://crates.io/crates/octocrab)
crate for GitHub. **You do not need the `jj` binary installed.**

| Tool | Why | Notes |
| --- | --- | --- |
| **[git](https://git-scm.com/)** | colocated repo + fetch/push | jjk keeps a colocated git repo and uses `git` for network transport, hooks, and the staging area |
| **A GitHub token** | GitHub PR operations | only needed for `push` / `submit` / `sync`. jjk reuses your existing auth: it reads `$GH_TOKEN`/`$GITHUB_TOKEN`, or falls back to `gh auth token` if you have the [`gh` CLI](https://cli.github.com/) |
| **A jj identity** | authoring commits | set once, globally |

Authenticate GitHub — either export a token or sign in with the `gh` CLI (whose token jjk reuses):

```bash
gh auth login        # or: export GITHUB_TOKEN=...
```

Configure a jj identity so your commits aren't authored anonymously (jjk reads jj's standard config,
including `$JJ_CONFIG`):

```bash
jj config set --user user.name  "Your Name"
jj config set --user user.email "you@example.com"
```

> If you don't have the `jj` binary, set `user.name`/`user.email` in `~/.config/jj/config.toml` directly.

Interactive editing (`commit -i`, `commit --split`, `resolve --interactive`) opens whatever you
configure as jj's `ui.diff-editor` / `ui.merge-editor` (an external/GUI tool, your `$EDITOR`, or the
built-in TUI) — driven in-process, again with no `jj` binary required.

## Install jjk

`jjk` is a Rust binary. Build and install it from source with Cargo:

```bash
git clone https://github.com/sirmammingtonham/jjk
cd jjk
cargo install --path .
```

This drops the `jjk` binary into `~/.cargo/bin`, which is on your `PATH`. Re-run the same command to
upgrade after pulling changes; `cargo uninstall jjk` removes it.

Prefer not to install globally? Build and use the binary directly:

```bash
cargo build --release
./target/release/jjk --help
```

## Verify

```bash
jjk --help
jj --version   # 0.41.x is the tested version; jjk warns if yours differs
```

You're ready. Head to the [Quickstart](/quickstart).
